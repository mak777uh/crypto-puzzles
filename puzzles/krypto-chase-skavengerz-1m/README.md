# Krypto Chase × Skavengerz — общенациональная охота США, $5 000 за квалификацию / $1 000 000 финал

**Тип**: физическая GPS-охота с шифрованными подсказками (мобильное приложение Skavengerz).
**Статус**: анонс 2026-10-08 (PR Newswire), серия стартует в Юте (Wasatch Front); **нерешена**, квалификаций ещё не сыграно.
**Приз**: **$5 000** за каждую штатную квалификацию (выплата в BTC или наличными) → **$1 000 000** в национальном
чемпионате для одного финалиста.
**Механика**: «серия загадочных подсказок → реальные локации», проверка продвижения по GPS, QR-коды,
цифровые чекпоинты; побеждает первый, кто собрал всю цепочку за выходные (пятница утро — воскресенье вечер).
**Вход**: регистрация через приложение Skavengerz; дата квалификации объявляется только после набора 200 участников;
регистрация ограничена (детейла по цене входа в пресс-релизе нет — уточнять на сайте).

## Вердикт для нашей базы (2026-10-18, Qoder)
Не наш скоуп: (1) призовой фонд не в ончейне, выплата — «Bitcoin или cash» по решению организатора;
(2) нужен физический выезд в конкретный штат США в конкретные выходные; (3) возможная платная регистрация.
Занесена как **свежий источник новых охот** (серия будет идти по всем 50 штатам) и объект мониторинга:
если подсказки уходят в сеть (ончейн-адрес, OP_RETURN, хеш) — появляется удалённо-решаемый слой.
