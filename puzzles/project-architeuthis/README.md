## Подробности
- Криптографический рекрутинговый challenge, запущенный ВМС США в 2014 году.
- Идея заимствована у Cicada 3301: цепочка загадок для отбора кандидатов в криптологи.
- Успешные участники получали контакт с рекрутерами, а не денежный приз.
- Важен как прецедент: государственная структура использовала ARG-формат для найма.

## Зацепки / следующий шаг

- Использовать как пример дизайна рекрутинговых ARG.
