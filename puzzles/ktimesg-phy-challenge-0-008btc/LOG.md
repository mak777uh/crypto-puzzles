## Предрегистрация осей (правило №2 — до прогона)
- **H11a — пароль PGP.** Оракул точный и мгновенный: после S2K → AES-256-CFB дешифровка SEIPD → проверка MDC (SHA-1 от открытого текста) и валидность пакета Literal (24 байта). Кандидаты = только **упомянутые в самих материалах** строки (автор: «the password's already mentioned»): уникальные токены и фразы OP-текста, заголовок темы, ники, строка подписи, decode-результат мета-хинта (flabit/Zephyrus/Mox и склейки), названия из 19 официальных хинтов. Ожидаемый объём ≈ 400–1 000 кандидатов, ≤ 3 мин на 16 ядрах. Хит = валидный MDC (ложноположительный ~2^-120).
- **H11b — чтение k из тона/стороны.** Построить детерминированные потоки из 256 маркеров по восстановленным порядкам (position / draw_order / 4 таблицы / угол / радиус) над свойствами, которые автор назвал каналом: тон кожи (0..5), зеркальность (8 id), сторона A/B. Кандидатов на ось: десятки (не сотни тысяч), каждый → точный ECDSA-оракул `(k·G).x mod n == r` и `pub((s·k−z)·r⁻¹) == 02425afd…6650eb`.
- Ограничения: ≤10⁵ кандидатов и ≤15 мин на прогон; трат/трансляций нет; статус Илья-заморозки 14.10 «do not touch» **зафиксирован и вынесен пользователю на решение** (план 18.10 поставил Phy в #2) — работа ведётся только аналитическая, без обращений к автору и без сети, кроме read-only Wayback/GitHub.
