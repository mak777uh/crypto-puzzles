you can get k this way as well


k = e * (s - r*c)^-1 mod n

c = d * k^-1 mod n


e = the message hash

s = the posted s

r = the posted r

n = the curve order

k = the nonce

d = the private key

c = d over k

it comes from the one relation, s * k = e + r * d mod n, with d replaced by c * k

the test of a candidate c is one point multiply: c * R == Q, where R = k * G and Q = d * G
