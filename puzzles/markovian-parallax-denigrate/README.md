## Обновление (2026-10-16, deepseek-flash — web-исследование)
- Тип: уточнение + скептическая оценка
- Суть:
  - **1996** — по Usenet (группы `alt.religion.christian.boston-church`, `alt.music.smashpumpkins` и другие) прокатилась
    серия из **сотен** сообщений с бессвязным текстом из случайных слов: «jitterbugging McKinley Abe break Newtonian inferring caw…».
  - Заголовок **«Markovian parallax denigrate»** встречался лишь у части сообщений; по данным ciphermysteries.com,
    эти три слова просто **чаще других встречались в телах** сообщений.
  - Отправители маскировались под реальные адреса — например, `Susan_Lindauer AT WORF.UWSP.EDU (Chris Brokerage)`
    (адрес студентки Университета Висконсин-Стивенс-Пойнт был **подделан**, спуфинг). Сама Линдауэр отрицала связь.
  - **2012** — Кевин Моррис (The Daily Dot) назвал это «старейшей и страннейшей загадкой интернета», после чего о ней начали писать массово.
  - Основные версии: ранний экспериментальный чат-бот или генератор текста, троллинг/спам, эксперимент программиста с цепями Маркова.
