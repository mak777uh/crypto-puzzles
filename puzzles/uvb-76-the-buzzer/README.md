## Подробности
- Коротковолновая станция на частоте ~4625 кГц, непрерывно передающая гудок (25-50 гудков в минуту).
- Иногда гудок прерывается голосовыми сообщениями на русском — короткие кодовые фразы и позывные.
- Основные гипотезы: система «удержания частоты» для военной сети, канал связи, тестовый передатчик.
- Официального подтверждения назначения нет; станция продолжает работу десятилетиями.
- Радиолюбители ведут постоянный мониторинг и архивируют все голосовые вставки.
