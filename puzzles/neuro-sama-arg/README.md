## Обновление (2026-10-16, deepseek-flash — web-исследование)
- Тип: детализация + прогресс по сезонам
- Суть:
  - ARG запущен разработчиком AI-VTuber Нейро-самы под ником **Vedal**.
  - **Первая находка — 27 мая 2023:** за 2 минуты 27 секунд до начала стрима, где впервые показали модель Neuro V2,
    зрители заметили **жёлтый QR-код**; после коррекции перспективы он вёл на YouTube-канал **`_neurosama`**.
  - Канал публикует видео в мрачном чёрно-белом стиле: каждое содержит **песню и зашифрованный текст в описании**;
    ключи прячутся в текстах песен.
  - **Первый сезон** (Numbers, Study, Public Static Void, Numbers II, hello world!) в основном **решён** сообществом:
    - «Numbers» — ключ `1bad0fcabc1ebdce` собран из подсказок в тексте песни и применён к **AES-128-ECB**;
    - «Numbers II» — использовались AES-256, затем AES-128, ключ `3455861094181771` (последовательность Фибоначчи + числа песни),
      в аудио найдены спектрограммы с указанием «1ST=256BIT 2ND=128BIT X/26YZ».
  - В расшифрованных текстах — монологи «студента», считающего мир симуляцией, упоминания сестры, которая не вернулась домой,
    фразы «I don't want to be an engineer», «is that someone knocking on the door??».
  - **Второй сезон** ([Filtered], Meaning of life, Candles, Numbers III) остаётся **нерешённым**:
    по данным вики на **12 октября 2025** три последних видео канала не расшифрованы из-за нехватки зацепок и людей.
  - Сообщество ведёт вики (**zh.neurosama.info / NeuroWiki**), блог разбора **neuro-arg.github.io/posts/** и Google Drive с материалами.
