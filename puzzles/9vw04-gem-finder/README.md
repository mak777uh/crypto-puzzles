## Структура, подтверждённая 2026-10-18 (Qoder; детали — LOG.md, data/EXTERNAL_DIGEST.md)
- Сетка прочитана окончательно: `data/grid_ocr5.json` (сверка EasyOCR × ручная транскрипция canalqb × шаблоны глифов × цвет; 1050/1050 клеток в своём классе).
- Строка = 25 пар (буква, цифра); **буквенный канал избыточен**: letters[r][j] = cyc[(j−r) mod 26], цикл `TUVWYZROBMJKHLXQNPACDEFGIS` (26 букв); головы строк = «T» + реверс цикла («look in the mirror» — структурно подтверждено).
- Поправки OCR: 20 клеток диагонали «2»→**Z** и 20 серых клеток «0»→**O** (прежний skip-перебор 17.10 сидел на неверных символах + оракул wif_bruteforce2.py имел баг len==34 — ни один WIF не проверялся; исправлено в tools/skip_ocr5.py).
- Целевой формат ключа подтверждён ончейн (witness трат): **compressed WIF, 52 символа, старт K/L**.
- Закрыто негативом (0 валидных WIF из ~9850 кандидатов): skip-окна по 10 порядкам grid_ocr5; то же для Atbash-зеркала; сигнатура маски 9,V,W,?,4 на интервалах; цвет-меченые потоки; (letter,digit)→base58 4 маппинга; спирали in/out; skip по текстам всех постов.
- Реальный носитель данных в сетке — цифровой поток 525 цифр + цветовые метки; правило «сетка→WIF» остаётся неизвестным (инсайт-оси исчерпаны, см. PROPOSALS «исчерпано»).
