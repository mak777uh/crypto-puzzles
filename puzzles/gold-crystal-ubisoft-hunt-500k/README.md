# Gold & Crystal — The Lost Treasure of Edward Kenway (Ubisoft × Unsolved Hunts, $500 000)

**Тип**: физическая охота за кладом с платным входом (не on-chain пазл).
**Статус**: анонсирована 2026-05-13, открыта/нерешена; старт прохождения — 2026-11-09 (по данным sknr.net).
**Приз**: реальный клад стоимостью **$500 000** (золото + кристалл), спрятан в Карибском регионе; победитель
летит на место и достаёт сундук сам.
**Механика**: **15 головоломок** (карты, письма, архивы, «послание в бутылке»); часть решается удалённо,
финальный шаг — физический поиск. Ubisoft оценивает срок решения в **2–5 лет**.
**Вход**: от **~$40** (платный доступ через Unsolved Hunts).
