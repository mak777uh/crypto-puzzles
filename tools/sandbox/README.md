# Песочница (`tools/sandbox/`) — watch-only + сторож призов

Создана 2026-10-19 по решению Ильи: «кошелёк песочницы» = **watch-only** (никаких приватных
ключей) + **сторож призов** (сигнал о новом он-чейн событии) + **подготовка неподписанного PSBT**
(подпись и broadcast — только руками Ильи).

## Состав

| Файл | Что делает | Сеть |
|---|---|---|
| `watchonly.json` | список наблюдаемых адресов с меткой `kind` (`prize` — наш призовой эскроу, `external` — чужой кошелёк: решатель/автор/hot wallet) | нет |
| `monitor.py` | читает `chain_stats` + последние OP_RETURN по каждому адресу, сравнивает с `state.json`, при изменении дописывает запись в `puzzles/<slug>/LOG.md` | только GET `blockstream.info/api` |
| `psbt_prepare.py` | из UTXO наблюдаемого адреса собирает **неподписанную** транзакцию и PSBT (BIP174) с оценкой комиссии; файлы кладёт в `--outdir` (по умолчанию `reports/drafts/`) | только GET |
| `state.json` | последний снимок состояний (создаётся `monitor.py`, в него писать руками не нужно) | — |

## Как запускать

```bash
python tools/sandbox/monitor.py                 # один проход сторожа (первый запуск = seed)
python tools/sandbox/monitor.py --quiet         # печатать только изменения
python tools/sandbox/monitor.py --no-log        # сверить, но не трогать LOG.md пазлов

python tools/sandbox/psbt_prepare.py <адрес-приза> \
    --destination <адрес-назначения-от-Ильи> --fee-rate 2 --slug <slug>
```

Флаг `--destination` обязателен и **его пока некому выдать**: в `watchonly.json`
`wallet.destination_address = null`. До того как Илья назовёт адрес назначения, `psbt_prepare.py`
можно запускать только для проверки механики (тестовый адрес), черновики в `reports/drafts/`
при этом помечаются `status: UNSIGNED`.

## Что песочница не делает никогда

- не хранит и не запрашивает приватные ключи, сиды, xprv (правило №6 `AGENT_INSTRUCTIONS.md`:
  ключи — только в `.secret/` вне OneDrive и только лично Ильё);
- не подписывает и не транслирует транзакции, не тратит деньги (правило №5: никаких трат без ОК);
- не пишет секреты в `LOG.md`/`README.md`/отчёты;
- не использует платные API.

## Транспорт

Единственный рабочий источник чтения с этого хоста — `https://blockstream.info/api` (GET, ~1 с/адрес).
`mempool.space` после массовых чтений агентами 19.10.2026 отвечает 429/пусто, `urllib` падает по TLS —
поэтому оба скрипта ходят через `curl` и держат паузу между запросами.

## Смысл списка наблюдения

1. `prize` — живые призовые эскроу, за которыми сто́ит следить: пополнение, возврат приза,
   новая стадия автора, OP_RETURN-хинт. Любое из этих событий = основание по §5 вернуть/вывести
   папку в активную работу. В списке: LuckyLurker Vault #2 (1 BTC), ONFO (1 BTC), Licorne (0,21021 BTC),
   GSMG `1GSMG…` (1,25649674 BTC), bitaps Shamir (1,00016775 BTC), опустевшие эскроу CaesarCoder
   и LuckyLurker seed-riddles (ловим новое пополнение), адрес пазла Natasha.
2. `external` — чужие кошельки, которые агенты раньше ошибочно принимали за призы: Natasha
   (`36T9H8…`), решатель LuckyLurker (`17oKQH…`), автор CaesarCoder (`bc1qw8…`), адрес свипа Genesis
   (`bc1qdu8m…`), GSMG-«halving» выход (`17ucy…`). Наблюдаем, чтобы не перепутать с призом;
   это **не цели охоты**.

## Связь с очередью

`monitor.py` дешёвый (13 адресов ≈ 30 с) и безопасный — его можно вызывать в начале каждого прохода
самобудильника: `python tools/sandbox/monitor.py --quiet`. Изменения появятся в `LOG.md`
соответствующих пазлов с пометкой `sandbox-watch`; повторная запись по тому же событию не дублируется
(в блоке есть строка `Маркер: [sandbox-watch <дата>Z <адрес> <тип_изменения>]`, по ней и проверяется).
