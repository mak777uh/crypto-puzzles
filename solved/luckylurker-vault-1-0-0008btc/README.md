    BIP39 отвергает её контрольную сумму, и даже пропуск проверки даёт не тот кошелёк.
    Путь деривации — **`m/0'/0/1`** (второй принимающий адрес), **не** BIP84.
  - **Выплата:** 17 августа 2026, 18:08:09 UTC, транзакция
    `75e570a5ea243c492e2804916482f046b2392b463c51be15624e6e25a84119f7` потратила два выхода по 40 000 сатоши:
    79 638 сатоши на `17oKQHHRxdQBiRaGKCoVDQJfebhPaZV3r7` + 362 сатоши комиссии.
  - Автор подтвердил решение в статье «LuckyLurker Bitcoin Vault #1 has been cracked», но **имя решателя не назвал**.
